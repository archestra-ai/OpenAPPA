Open the dashboard:

  kubectl -n {{ .Release.Namespace }} port-forward svc/kagent-ui 8080:8080
  http://localhost:8080/agents/{{ .Release.Namespace }}/cluster-ops/chat
{{- if .Values.guide.enabled }}
  http://localhost:8080/agents/{{ .Release.Namespace }}/appa-guide/chat
{{- end }}

The cluster-ops agent opens with the showcase chats already there — every
demo case, as it ran: the exfiltration ask that leaks nothing, the agent
taking a sanitized remedy on its own, the chat steering it to accept the
change or to decline, a forged offer, the on-call approval, the annotator,
the release window, the remote change board approving, denying and
staying silent, delegation, and gated ingress. Run your own from the
same page.

{{- end }}

Prerequisite (once per cluster): kagent 0.9.12 installed with its agent
image set to the OpenAPPA runtime image, so every declarative agent is
gated — see the chart README.
