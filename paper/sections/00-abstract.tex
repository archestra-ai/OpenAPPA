LLM agents operating with broad authority over tools and data are vulnerable to confused deputy attacks when processing untrusted inputs~\cite{hardy1988confused,greshake2023not}. Content-based guardrails are easily bypassed, while static access controls severely degrade utility. Fides introduced dynamic information flow control (IFC) for agent planners to track security labels and enforce deterministic policies~\cite{fides}. However, observing unvetted data permanently taints an agent's execution trajectory. \appa{} builds upon this foundation by preventing trajectory taint accumulation before it occurs.

We present \appa{}, introducing \emph{branching as taint prevention}. Before executing any label-restricting tool call, the runtime forks a child trajectory at the parent's current label and dispatches the call exclusively within the child. The child absorbs any label descent from unvetted data, while the parent never observes the raw data and retains its unconstrained label. The child can then be discarded or merged back through a policy-checked exit point, allowing a trusted sanitizer to return a bounded derivative without unnecessarily polluting the parent context. This guarantees proactive taint prevention, respecting the non-reversibility of label descent~\cite{caiGhostAgentRedefining2026}.

\appa{} is governed by two monoids: a security label (audience $\times$ trust) and a globally shared event log that maintains action visibility across isolated trajectories. Prospective acquisition checks present sound options to accept, branch, sanitize, or decline label-restricting calls, while call-scoped rulings authorize controlled exceptions without ambient privilege elevation. We formally prove parent label preservation, monotone descent, merge confinement, and remedy completeness, and evaluate \appa{} on AgentDojo~\cite{debenedettiAgentDojoDynamicEnvironment2024}.
