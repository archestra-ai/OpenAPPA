LLM agents operate with broad authority over external tools and data, rendering them vulnerable to confused deputy attacks when processing untrusted inputs or mixed-confidentiality context~\cite{hardy1988confused}. In these environments, security risks such as unauthorized data exfiltration and policy violations arise structurally---whether driven by adversarial prompt injection, model hallucination, or errant tool usage---converting routine read access into security breaches~\cite{greshake2023not}. Content-based guardrails remain susceptible to bypass via prompt rephrasing, whereas static, coarse-grained access restrictions severely limit agent utility~\cite{fides}. Fides demonstrates a stronger approach in this design space by enabling an agent planner to track confidentiality and integrity labels, enforce deterministic policies, and selectively redact or reveal data to maintain utility~\cite{fides}. \appa{} builds upon this foundation, addressing how to prevent the planner's continuing execution trajectory from becoming tainted in the first place.

We present \appa{}, introducing \emph{branching as taint prevention}. Prior to executing any tool call that would restrict the trajectory's security label, the runtime forks a child trajectory at the parent's current label and dispatches the call exclusively within the child context. The child may process and inspect the raw result, absorbing any label descent; the parent never observes the unvetted data and thus retains its unconstrained trajectory label. The child can subsequently be discarded or return through a predeclared, policy-checked exit point whose resulting label is merged back into the parent. Returning a raw or restrictive result restricts the parent label upon merge, whereas a trusted sanitizer or quarantine-exit attestation can return a bounded derivative without unnecessarily tainting the parent. This mechanism provides taint prevention rather than retrospective untainting, as no operation can strip security labels from data already observed by a trajectory~\cite{caiGhostAgentRedefining2026}.

The framework is governed by two formal monoids: a security \emph{label} (audience $\times$ trust) and a globally shared \emph{event log}. A prospective acquisition check evaluates label-restricting calls, presenting sound options to accept, branch, sanitize, or decline. Shared event logging ensures process isolation never conceals physical actions or history predicates, while call-scoped rulings authorize controlled exceptions without ambient privilege elevation. We formally prove parent label preservation, monotone descent, merge confinement, and remedy completeness. Finally, we implement \appa{} as a pure decision core under a state-owning shell and evaluate it on AgentDojo~\cite{debenedettiAgentDojoDynamicEnvironment2024}.
