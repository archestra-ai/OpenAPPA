\paragraph{Closest comparison: \textsc{Fides} and Agent IFC}
\textsc{Fides} is the primary antecedent for \appa{}, formalizing dynamic information-flow control (IFC) for agent planners~\cite{fides}. While both share label-based enforcement decoupled from the LLM, they differ in mechanics (Table~\ref{tab:systems}). Structural frameworks like ACE~\cite{li2026ace} decouple planning into abstract and concrete phases for static verification. \textsc{Fides} mitigates label creep by evaluating tool outputs post-execution to hide restrictive fields in planner variables. In contrast, \appa{} evaluates acquisitions prospectively before data enters the trajectory, isolating sensitive sub-computations in disposable child branches and handling exceptions via single-call atomic rulings. By validating authority before execution, \appa{} prevents untrusted payloads from polluting the main planner context and triggering irreversible taint accumulation.

\paragraph{Semantic, memory, and provenance systems.}
Frameworks address distinct scopes across the agent lifecycle. MemLineage~\cite{ouyangMemLineageLineageGuidedEnforcement2026} gates actions on signed memory entry derivation graphs across sessions. In contrast, \appa{}'s trajectory labels and append-only event log govern single runs, enabling MemLineage to provide persistent provenance at \appa{}'s boundary. Offline tools like NeuroTaint~\cite{caiGhostAgentRedefining2026} perform post-hoc causal analysis across sessions, complementing \appa{}'s online enforcement. Execution provenance taxonomies~\cite{wangAgentTracesTrust2026} model typed graphs to trace semantic dependencies between inputs and output claims. In contrast, \appa{}'s event log records only operational tool actions and rulings, enforcing policy without tracking semantic claim attribution.

\paragraph{Process isolation vs.\ trajectory branching.}
Container and browser sandboxes — such as DeltaBox~\cite{dong2026deltabox}, Crab~\cite{wu2026crab}, and ceLLMate~\cite{meng2025cellmate} — provide OS-level checkpoint/restore and authority sandboxing, carrying classical OS dynamic IFC (Flume~\cite{krohn2007information}, HiStar~\cite{zeldovich2006making}) and floating-label IFC (LIO~\cite{stefan2011flexible}) into the agent setting. \appa{} operates orthogonally: while system sandboxes snapshot OS processes and filesystems, \appa{} confines label propagation at the LLM context trajectory layer, isolating unvetted tool data within child branches without memory rollback or hardware enclaves. Consequently, \appa{} can operate alongside process sandboxes to provide defense-in-depth across both OS environment and prompt context boundaries.

\paragraph{Guardrails and structural isolation.}
Imperative guardrails — such as NeMo Guardrails~\cite{nvidia2023nemoguardrails}, boundary sanitizers~\cite{bhagwatkarIndirectPromptInjections2025}, and Llama Guard~\cite{inan2023llama} — filter content without lineage tracking, leaving them vulnerable to paraphrasing or context drift. Structural patterns like Dual LLMs~\cite{willison2023dual} and CaMeL~\cite{camel2025} enforce isolation but require restructuring harnesses into multi-role architectures, while capability-safe harnesses like TACIT~\cite{odersky2026tracking} enforce static capabilities via code synthesis. In contrast, \appa{} operates dynamically at the tool-dispatch layer of standard harnesses via pre-dispatch hooks.
