\section{Atomic Rulings and Robust Declassification}\label{sec:rulings}

\paragraph{One judgment and one dispatch rule.}
Every judgment has one form: authority $A$ authorizes engine-rendered call $C$. There are no grant kinds or grant objects in configuration or on the wire; the public vocabulary comprises mandates, rulings, and log records. A call dispatches iff rulings cover every failed or demanded predicate, each issuer's mandate covers what that issuer admitted, and all rulings name the same rendered call and are consumed together atomically. Usually one ruling suffices; two-eyes policies collect several. A ruling admits dispatch despite a gap but never edits the trajectory, which changes only through the admitted call's own \texttt{delta} and \texttt{emits}. No ruling can replace the agent's deliberateness gate for narrowing (\S\ref{sec:enforcement}).

\paragraph{Atomic plan execution.}
For a ruling-carrying plan on a suspended run, one indivisible step renders the call, presents provenance---never value bytes---to the authority, and dispatches upon approval. The plan identifier, ruling, and dispatch enter the log together. Acceptance plans are trivially atomic: accept and dispatch require no authority round trip. Earlier drafts' issue--bind--spend--boundary-death grant discipline survives only as an internal invariant because approval and dispatch coincide. Nothing can intervene, the ruling names the rendered call so calls cannot be swapped, one review admits one dispatch so it cannot be replayed, and the event is reconstructible from the log. In linear terms, the consumable resource is spent in the same breath in which it is minted \cite{wadler1990linear}.

\paragraph{Call-scoped release.}
The sole ruling form covers one dispatch without changing the fold. The ruling and world event record the release while the label continues to describe what the data is. This matters especially in a taint-preventing branch: an exceptional send or exit cannot ambiently widen either child or parent for a subsequent attacker-steered call. The trajectory never holds widened state. A ruling-carried epoch-wide permissive delta is algebraically coherent but deliberately excluded: branching addresses its applied need (\S\ref{sec:branching}), with the tradeoff stated in \S\ref{sec:limitations}.

\paragraph{Mandate typology.}
Powers belong to declarations, not runtime objects, and each names its currency. A cover mandate admits trust-floor gaps up to a rank or recipient gaps up to a reader-set ceiling, without changing the label. A named waiver identifies the \texttt{no\_prior} event kinds it may except. An attends mandate identifies attention marks whose demands a ruling satisfies: tools and authorities refer to the mark rather than naming each other. One ruling may cover both a requirement gap and attention demand on one call, but never the narrowing-acceptance gate; two-eyes review uses two marks attended by different authorities. Acquisition is intentionally absent because accepting descent is a free agent plan, not granted power.

Scope is a separate jurisdiction axis routed exclusively by \texttt{tags}; trust, audience, and effects are checked currencies, never routing keys. Soundness is tag-independent because even a misrouted authority cannot exceed its mandate and still judges the rendered call. Only completeness depends on tags.

\paragraph{Response-sink rule.}
No end-user ruling may cover any predicate of a response-sink release, regardless of the user's other mandates. Because the approval request would arrive on the channel being released to, in-band self-confirmation is structurally not a check.

\paragraph{Canonical rulings and robust release.}
Authorities judge the engine's canonical rendering, closing the paraphrase channel in which a tainted model might ask to email a compliance archive while omitting an attacker-derived address. Remedy-set soundness supplies selection immunity: because each offered plan is independently sound, a tainted planner may continue choosing among them. In the what/who taxonomy, sanitization controls what is released and rulings control who may authorize it \cite{sabelfeld2009declassification}. For the benign-but-confusable actor, attacker-controlled suspicious content may control which requests the agent proposes, but cannot control which releases are admitted: admission still requires sink adequacy or a mandate-bounded ruling over the exact rendered call. This is the intended agentic analogue of robust declassification \cite{zdancewic2001robust}.

\paragraph{Sanitizers.}
Registered sanitizers transform values under mandated transitions; they never apply to a trajectory, because after-the-fact sanitization cannot make a context unobserve bytes already seen. At the output point, a derivation is admitted while the raw result remains confined, protecting context but requiring a confining deployment. At the input point, a derived value replaces the raw argument in the engine-rendered call, and the harness sends the redacted bytes. This protects a sink in any deployment but cannot undo context exposure that already occurred. The sink check uses the derivative's declared label instead of the raw argument's contribution; the trajectory label is unchanged and application is logged.

Sanitizer transitions change audience only: trust never rises through sanitization. A mechanical transformation may bound who can read its derivative, whereas a claim that output is now trustworthy is judgment requiring a ruling or cast. The sole structured exception is quarantine-exit attestation (\S\ref{sec:branching}). Mandates bind transitions rather than information: \texttt{remove\_pii} may be sound for CRM tickets yet launder a dataset consisting entirely of PII. Information-type scope is future work, and registration trusts the transformer rather than verifying each output. Casts are the second nongrant power for filling Unknown: they are constant or resolver-implemented under a declared target ceiling.

\paragraph{Sudo metaphor.}
A ruling resembles \texttt{sudo} only in the narrow, honest sense: one command receives one elevation, with nothing ambient afterward.
