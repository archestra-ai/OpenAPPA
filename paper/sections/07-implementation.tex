\section{Implementation}\label{sec:implementation}

\appa{} is implemented in two decoupled layers: an inner pure algebraic core that evaluates policy decisions deterministically over event log folds~\cite{schneider2000enforceable,wangAgentTracesTrust2026}, and an outer runtime that manages state persistence, context isolation, and dispatch hooks. State views (such as folded labels and pending plans) are passed homomorphically as log folds~\cite{pierce2002types}. The outer layer creates disposable child contexts, maintains trajectory isolation, and enforces return-label validation prior to merges.

\paragraph{Harness embeddability and session interface.}
\appa{} embeds into standard execution runtimes via pre-dispatch interceptor hooks and a host interface for session management. Creating a child context requires passing an explicit parent-session reference to seed the isolated child trajectory from the active parent state, leaving child session creation strictly under host control.

The implementation distinguishes two mechanisms for handling policy decisions and state transitions: (1)~the \emph{ordinary narrowing path}, which executes in-session via \texttt{execute\_remedy\_plan} (\S\ref{sec:enforcement}) to record narrowing acceptances and authorized rulings and open the dispatch without folding a Label directly—the Label reduction materializes only if the result, or a registered derivation of it, is admitted as a value; and (2)~the \emph{explicit branch path}, which initiates a host-requested child session bound to the parent-session reference, isolating restrictive data acquisition until an explicit merge or abandonment. Operating as a middleware layer, \appa{} transparently mediates tool dispatches directly at runtime. If a dispatch reports success but its result is oversized, cannot be resolved by a permitted cast, or cannot be admitted through its bound sanitizer, its effects remain committed while its withheld value contributes nothing to the trajectory Label.

\paragraph{Planner representation and search state.}
The Remedy planner operates over the finite state abstraction $(L, \mathcal{E}(\ell))$ comprising the committed Label $L \in S$ and the family-wide committed-effect projection $\mathcal{E}(\ell) \subseteq K$. Because Labels descend over finite domains and committed effect kinds only accumulate, the search state space is finite, enabling deterministic plan synthesis for atomic \texttt{Authorize}/\texttt{Accept} executables and curative \texttt{Redispatch} recommendations.

\paragraph{Log filtering and type invariants.}
Transcript construction projects the shared event log by trajectory identifier, ensuring child models observe only branch-local facts and preambles. History predicates evaluate over the family-wide committed-effect projection $\mathcal{E}$, while raw dispatch lifecycle facts remain preserved in the log for audit purposes.

State transition invariants are enforced statically through the host language's type system~\cite{pierce2002types}. Unannotated tool parameters default to \texttt{Unknown} and must pass through boundary validators or cast resolvers before participating in label arithmetic. The policy checker restricts operations to label arithmetic and log predicates, delegating imperative execution to registered external components.

Branch lifecycle operations---\texttt{fork}, \texttt{submit}, \texttt{abandon}, and \texttt{merge}---include stable parent and child identifiers. Property-based tests generate arbitrary child execution traces to verify Proposition~\ref{prop:preservation}:
\begin{itemize}
  \item child-only actions cannot mutate the parent fold,
  \item a merge operation consists of exactly one meet with the submitted value's label, and
  \item all successfully committed effects remain visible in the family-wide projection following abandonment, while failed and indeterminate dispatch facts remain available for audit.
\end{itemize}

\fixme{The configuration surface is deliberately undecided; constraints that every surface must preserve are listed below.}
Configuration contains mandates exclusively, omitting grant objects entirely. It enforces a strict \emph{no-empty-mandate rule}: an authority with a mandate covering no permissions triggers an explicit configuration loading error, as the correctness proof for empty \texttt{remedy\_plans} relies on this invariant. Block messages expose applicable remedy plans and specify eligible authorities whenever a plan includes a ruling. Every audience specification explicitly declares its set relation---includes, exactly, or may-add---and scope routing is governed exclusively by tags. Type casts are restricted to constant definitions or resolver implementations.
