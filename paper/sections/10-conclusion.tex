\section{Conclusion}\label{sec:conclusion}

Traditional information flow control prevents data leaks, but dynamic tracking mechanisms create a severe usability bottleneck by permanently restricting context after sensitive operations~\cite{fides}. APPA addresses this usability bottleneck through a formal, structural branch lifecycle:
\begin{itemize}
  \item pre-evaluating data acquisitions prior to dispatch,
  \item isolating restrictive reads in disposable child branches, and
  \item merging only policy-compliant results back into the main trajectory.
\end{itemize}
By bounding label scope and maintaining a unified event log across execution paths, APPA keeps the parent context clean without relying on ad-hoc sanitization or prompt-level mitigations~\cite{camel2025,willison2023dual}. Ultimately, APPA demonstrates how agent hosts can enforce rigorous security policies while preserving context continuity and task capability.
