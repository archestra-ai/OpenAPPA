\section{Conclusion}\label{sec:conclusion}

Label-based enforcement can stop unsafe releases and still leave an agent too tainted to do useful work. APPA's central claim is that this loss is not inevitable: make the acquisition decision before dispatch, fork the restrictive read into a disposable child, and admit only a policy-bounded result back into the continuing trajectory. The parent is preserved by label-fold locality and meet, while a shared event log prevents isolation from rewriting world history. The policy algebra, remedy enumeration, and atomic rulings matter because they make this branch lifecycle structural rather than prompt-based. APPA does not untaint a context; it arranges for the useful context never to observe the taint.
