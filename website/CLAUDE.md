# CLAUDE.md — website

This directory is the marketing/docs website (Next.js, pnpm). Its content
can drift from the actual project and is **not** a source of truth.

**When working on anything APPA-related (engine semantics, terminology,
contracts), use `appa-engine/src/lib.rs` as the source of truth.** If the
website contradicts it, the website is wrong — never propagate its
wording, claims, or terminology back into any APPA discussion.

Edits flow one way only: into the website, never the reverse.
